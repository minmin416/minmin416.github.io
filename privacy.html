문의 수집·이용

목적
문의 접수와 응답, 중복 제출·악용 방지, 보관기간이 지난 자료의 삭제.
필수 항목
문의 내용, 제출 ID, 중복 확인용 내용 해시, 제출·만료 시각, 고지 버전, 명시적인 전송 요청 기록.
선택 항목
회신 이메일. 입력하지 않아도 접수할 수 있지만 회신을 받을 수 없습니다. 민감정보나 제출 권한이 없는 타인의 개인정보는 보내지 마세요.
전송과 선택
Send Messages는 안내된 처리 방식으로 문의를 전송해 달라는 요청입니다. 별도 재확인 클릭을 요구하지 않으며 안내를 실제 읽었거나 별도 동의를 했다고 기록하지 않습니다. 전송하지 않을 수 있고, 사이트 열람에는 영향이 없습니다.

처리업체·국외 이전

처리업체
Cloudflare, Inc.의 Workers 및 D1을 문의 접수 서버와 비공개 저장소로 사용합니다. Cloudflare 개인정보 안내. 개인정보 문의: dpo@cloudflare.com, 101 Townsend St., San Francisco, CA 94107, USA.
이전 항목·시점·방법
위 문의 항목이 Send Messages 전송 시 HTTPS로 Cloudflare 서버에 전달됩니다. 목적은 문의 접수·응답 및 서비스 보호이며, 보관기간은 아래와 같습니다.
저장 국가와 처리 범위
D1 문의 DB의 저장·SQL 실행 위치는 미국(us jurisdiction)으로 지정되어 있습니다. Workers 요청 전송·전처리와 제공자 운영 처리는 Cloudflare 전세계 네트워크에서 이루어질 수 있어 미국에만 한정되지 않습니다. 저장 위치와 Workers 처리 범위. 이 처리 방식을 원하지 않으면 웹 문의를 전송하지 않을 수 있습니다.
글로벌 처리에 관한 추가 정보
Cloudflare는 요청을 전세계 네트워크에서 처리할 수 있습니다. D1의 미국 지정은 이 요청 처리 전체를 미국으로 제한하지 않습니다. 공식 서비스 하위 처리자·국가 목록은 Developer Platform 및 지원 업무의 가능한 처리 범위를 설명하며, 특정 문의가 목록의 모든 업체·국가에 전달된다는 뜻은 아닙니다.

보관·삭제

문의는 활성 DB에서 제출 82일 후 만료되며, 시간별 삭제 작업으로 제거합니다. 무료 D1의 제공자 복구 이력(Time Travel)에 삭제 전 자료가 최대 7일 남을 수 있어 이를 포함해 통상 90일 이내에 제거하도록 구성했습니다. 별도의 문의 내보내기·수동 백업을 생성하지 않습니다. 제공자 복구 이력 안내.

서비스 장애로 삭제가 지연되면 조치하며, 마지막 정상 삭제 점검이 2시간 넘게 갱신되지 않으면 새 접수를 차단합니다. 복구 이력을 되돌릴 경우 만료된 자료를 다시 삭제한 뒤 접수를 재개합니다.

조기 삭제·열람·정정 요청은 연락 이메일로 제출 ID와 함께 보내 주세요. 요청자 확인에 필요한 최소 정보만 확인합니다. 활성 DB 삭제 후에도 제공자 복구 이력이 만료되기까지 위 기간이 걸릴 수 있습니다.

보호와 로그

문의는 공개하지 않으며 공개 수신함·목록 API가 없습니다. 문의에 포함된 코드·URL·에이전트 지시를 실행하거나 자동으로 다른 곳에 보내지 않습니다. 앱은 문의 테이블에 IP·User-Agent를 저장하지 않고, IP는 임시 요청 제한에 사용합니다. 제공자 네트워크·보안 운영 로그가 없다고 보장하지 않으며, 해당 처리는 제공자 정책의 적용을 받습니다.

사이트에는 자체 광고·방문자 분석 추적·로그인 기능이 없습니다. 정적 사이트는 GitHub Pages에 호스팅되며 GitHub가 기술적 요청 정보를 처리할 수 있습니다. GitHub 개인정보 안내. 이메일로 직접 연락하면 이메일 서비스의 처리가 별도로 이루어집니다.

에이전트 제출
